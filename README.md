# Penguin Playground

An HTML homepage with a movable 3D penguin, built with JavaScript and Three.js.

## Run

Use Node.js 22 or newer. No dependency installation is required:

```sh
npm start
```

Open port 3000 in your browser. Set `PORT` to use another port.
The browser must support WebGL.

## Controls

- Arrow keys or WASD: move around the snow island.
- On-screen arrows: move using touch or a pointer.
- Drag across the scene: rotate the penguin.
- Reset position: return to the center.

Three.js 0.170.0 is bundled in `vendor/` under the included MIT license.
